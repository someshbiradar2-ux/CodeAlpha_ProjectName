# Netflix EDA and Data Visualization Project

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) and Data Visualization on the Netflix Movies and TV Shows dataset.

The objective is to understand the content available on Netflix and identify useful patterns and trends based on factors such as content type, release year, country, genre, rating, and duration.

## 📂 Tasks Completed

### Task 2 – Exploratory Data Analysis

- Loaded the Netflix dataset using Pandas
- Examined the dataset structure and dimensions
- Checked data types
- Identified and handled missing values
- Checked for duplicate records
- Analyzed content types
- Analyzed release years
- Analyzed countries
- Analyzed genres/categories
- Performed descriptive statistical analysis

### Task 3 – Data Visualization

- Created visualizations for Netflix content
- Compared Movies and TV Shows
- Analyzed release-year trends
- Visualized country-wise content distribution
- Analyzed popular genres/categories
- Used charts to identify important patterns and trends

## 📊 Dataset

The project uses the Netflix Movies and TV Shows dataset containing:

- 8,807 records
- 12 columns
- Movies and TV Shows
- Information about title, director, cast, country, release year, rating, duration, genre, and description

## 🛠️ Technologies Used

## 📁 Project Files

- `Netflix_EDA_Project.ipynb` – Task 2: Exploratory Data Analysis
- `Netflix_Data_Visualization.ipynb` – Task 3: Data Visualization

## 🔍 Key Findings

- Movies are more numerous than TV Shows in the dataset.
- The United States has the highest number of titles.
- India is one of the major countries represented in the dataset.
- 2018 has the highest number of titles by release year in this dataset.
- Dramas, International Movies, Documentaries, and Stand-Up Comedy are among the frequently occurring categories.
